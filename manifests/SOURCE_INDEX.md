# Source index

This is a curated code-and-sealed-table mirror for the paper. `code/` contains the R3--R8 and R8-FIX execution/statistics code and paper analysis helpers; `figures/` contains plotting scripts and their sealed tabular inputs; `tables/` contains sealed summary tables, claim evidence, discrepancies, and corrections; `protocols/` contains preregistration/execution documents and sealed receipts; `manifests/` contains small case/provenance manifests.

Per-run raw trajectories, datasets, caches, checkpoints, and weights are excluded from GitHub. Their source paths and SHA-256 values are retained in the claim ledger and sealed manifests; raw result archives are prepared separately for Zenodo.
